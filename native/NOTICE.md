# Elder native release notice

The native parameter ABI, generated profile format, color pipeline, shader
integration, tests, and packaging in this directory are original Elder ENB
work. No third-party shader source, decompiled source, ENBSeries binary,
Address Library binary, Microsoft compiler binary, or test executable is
redistributed in the native release package.

The packaged `.cso` is an Elder build artifact. The accompanying `.asm` is a
human-readable release-audit artifact produced from the same Elder shader
entry point; it is not a third-party runtime component.

No public distribution license has been selected for this project yet. This
notice is not a license. The project owner must select the release license
before publishing the package.
