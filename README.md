# Elder ENB - Universal

> A modular ENB visual framework for Skyrim Special Edition - 190+ overlays across 15 categories, built on the Silent Horizons shader core.

![license: proprietary](https://img.shields.io/badge/license-proprietary-lightgrey.svg)
![HLSL](https://img.shields.io/badge/shaders-HLSL-orange.svg)
![ENB shader research](https://img.shields.io/badge/ENB-shader%20research-D4AF37.svg)

Elder ENB is not a single preset but a visual vocabulary: a library of modular ENB
overlays (bloom, color grading, cinematic effects, depth of field, and more) that can
be mixed and layered to define a personal look. The repository holds the preset and
overlay `.ini` configurations, ENB effect shaders (`.fx` / `.fxh`), bundled shader
utilities, and the PowerShell / Python / xEdit tooling used to generate, audit, and
synchronize preset data.

## Requirements

- [ENB Binary](http://enbdev.com/) (Wrapper version - `d3d11.dll` only)
- Silent Horizons 2 - Shader Core
- ENB Extender & Helper (+ prerequisites)
- KreatE (+ prerequisites)
- KiLoader (+ prerequisites)

See `MOD_DESCRIPTION.txt` for full installation, usage, and credits.
